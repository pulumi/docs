*********************
pulumi_cloud_sdk.apis
*********************

.. py:module:: pulumi_cloud_sdk.apis

``pulumi_cloud_sdk.apis`` contains one client class for each Pulumi Cloud API area, such as ``StacksApi``, ``OrganizationsApi`` and ``EnvironmentsApi``. Each method calls one REST endpoint and takes and returns types from :doc:`models`. Create an ``ApiClient`` from ``pulumi_cloud_sdk`` and pass it to an API class.
