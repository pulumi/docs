Class Json

Shared, pre-configured Newtonsoft.Json settings for the generated SDK.

Newtonsoft.Json.NullValueHandling.Ignore drops unset properties on serialization (matching the Python/TypeScript reference clients, which omit unset values on the wire). DateParseHandling.None leaves untyped JSON (JToken fields) exactly as received — typed DateTimeOffset properties are still parsed from ISO-8601 by their declared type. Polymorphic (discriminated-union) models resolve through the per-type PolymorphicConverter attached by the generator, not through Newtonsoft's $type metadata, which is therefore disabled.
