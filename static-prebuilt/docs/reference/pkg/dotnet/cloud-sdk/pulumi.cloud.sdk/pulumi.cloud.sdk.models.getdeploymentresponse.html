Status

The current execution status of the deployment. not-started means the deployment is waiting in the queue. The Pulumi Cloud console shows it as Queued, or as Paused when deployments are paused for the stack or the organization. accepted means the deployment has been taken off the queue for execution but has not started running yet. The console shows it alongside running. Webhook payloads report both not-started and accepted as queued. running means at least one step has started and no step has failed. failed covers, for example, a failed step, a timeout, or a cancellation, whether the deployment was queued or running. skipped means the deployment was removed from the queue without running, either because operationContext.options.skipIntermediateDeployments is enabled for it and a newer deployment of the same operation is queued right behind it for the same stack, or because it was still queued seven days after it was created. Once the deployment's job has started, this matches the job's status.
