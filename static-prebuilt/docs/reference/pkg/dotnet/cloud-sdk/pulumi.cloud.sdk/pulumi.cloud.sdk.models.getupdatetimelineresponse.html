CollatedUpdateEvents

CollatedUpdateEvents is the set of update events that are "relevant" to the update. It will contain the sequences of previews that were performed in the same "group", e.g. a GitHub PR, that lead to the final update. If the sequence of previews happened spanned when the stack was updated, e.g. the first preview was at version N - 1 and the last preview was at version N + 1, then the update to stack version N will be included. Will be empty if the update couldn't be associated with a particular sequence of previews.
