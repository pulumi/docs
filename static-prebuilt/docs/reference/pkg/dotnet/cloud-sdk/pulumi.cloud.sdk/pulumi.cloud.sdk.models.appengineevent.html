Sequence

Sequence is a unique, and monotonically increasing number for each engine event sent to the Pulumi Service. Since events may be sent concurrently, and/or delayed via network routing, the sequence number is to ensure events can be placed into a total ordering. - No two events can have the same sequence number. - Events with a lower sequence number must have been emitted before those with a higher sequence number.
