Class ApiClientConfiguration

Connection settings shared by every generated *Api class.

Host is the API origin (no /api suffix — the generated resource paths already start with /api/...). AccessToken supplies the Pulumi access token sent as Authorization: token <token>; it is a delegate so a rotating token can be re-read per request. Return null for unauthenticated requests.
