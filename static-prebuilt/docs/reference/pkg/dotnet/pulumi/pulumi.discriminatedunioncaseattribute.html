Class DiscriminatedUnionCaseAttribute

Attribute used to declare one member of a discriminated union interface marked with DiscriminatedUnionDiscriminatorAttribute. Tag is the discriminator property value that selects this member, and Type is the concrete OutputTypeAttribute class to instantiate; it must implement the annotated interface.
