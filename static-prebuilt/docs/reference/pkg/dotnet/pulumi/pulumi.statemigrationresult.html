Class StateMigrationResult

StateMigrationResult is returned by a state migration callback when it changes the state. Every resource present in the old state must either be returned in NewState under the same URN or have an entry in Successors, but not both.

This API is experimental and may change.

Successors

Maps each old URN removed from the state to the URN in NewState that succeeds it. Multiple old URNs may map to the same successor. A resource cannot be removed without a successor. The engine uses these mappings to rewrite resource references.
