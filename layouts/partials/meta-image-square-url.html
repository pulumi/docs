{{- /* The optional SQUARE (1:1) social card for a page, as a site-relative URL, or "" if none applies. Emitted by head.html as a second og:image (the landscape meta-image-url.html stays the primary og:image + twitter:image). Mirrors meta-image-url.html's precedence: 1. A page-level `meta_image_square` (custom override — always wins). 2. Blog posts: a 628x628 center crop of the post's `feature_image`, or of the generic blog plate (the same art the landscape card falls back to) when it has none. No title — it's the thumbnail Slack/LinkedIn show in small unfurls, where they'd otherwise center-crop the landscape card and slice its title. 3. A build-time generated square card at assets/images/generated/.square.png, if one exists (events only today). 4. "" (no second og:image is emitted). 2 and 3 are suppressed when the page sets a custom `meta_image`, since a custom landscape override has no matching square. */ -}} {{- $img := "" -}} {{- if .Params.meta_image_square -}} {{- if eq .Section "blog" -}} {{- with .Resources.GetMatch .Params.meta_image_square -}}{{- $img = .RelPermalink -}}{{- end -}} {{- else -}} {{- $img = .Params.meta_image_square -}} {{- end -}} {{- else if not .Params.meta_image -}} {{- if and (eq .Section "blog") (eq .Kind "page") -}} {{- $src := "" -}} {{- with .Params.feature_image -}}{{- $src = $.Resources.GetMatch . -}}{{- end -}} {{- if not $src -}}{{- $src = resources.Get "images/blog/feature-generic.png" -}}{{- end -}} {{- with $src -}}{{- $img = (.Fill "628x628 Center png").RelPermalink -}}{{- end -}} {{- else -}} {{- with partial "meta-image-key.html" . -}} {{- with resources.Get (printf "images/generated/%s.square.png" .) -}} {{- $img = .RelPermalink -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $img -}}
