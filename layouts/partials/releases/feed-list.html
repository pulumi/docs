{{/* Releases Feed List One bordered .card holding up to two lists — blog posts and related events — each under its own overline. Rows come from the shared compact list-row components, so both lists line up on the same columns. An event stays on the page for as long as events/is-current.html says it's worth a click — while it's still ahead of us, and afterwards for as long as it has a recording, in which case its row flips itself from Register to Watch. An event that has run with nothing to watch drops off, and the heading goes with the last of them, so the card can never advertise a date that has passed. An event pinned as the page's featured_event shouldn't also be listed here; the two keys are read literally, so listing it in both renders it twice. Parameters: - anchor: Optional section ID for TOC link targets. - posts_title: Overline above the posts. Defaults to "More from the blog". - posts: Array of blog post paths (e.g. "/blog/some-post"). - events_title: Overline above the events. Defaults to "Related events" — the list mixes upcoming and on-demand, so it isn't "Upcoming". - events: Array of event paths (e.g. "/events/some-event"). Both lists are looked up via site.GetPage; missing pages are skipped. */}} {{ $anchor := .anchor }} {{ $postsTitle := .posts_title | default "More from the blog" }} {{ $eventsTitle := .events_title | default "Related events" }} {{ $posts := slice }} {{ range .posts }} {{ with site.GetPage . }}{{ $posts = $posts | append . }}{{ end }} {{ end }} {{ $events := slice }} {{ range .events }} {{ with site.GetPage . }} {{ if partial "events/is-current.html" (dict "page" .) }} {{ $events = $events | append . }} {{ end }} {{ end }} {{ end }} {{ if or $posts $events }} {{ with $posts }}
