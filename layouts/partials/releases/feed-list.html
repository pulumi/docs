Rows come from the shared compact list-row components, so both lists line up on the same columns. Events are filtered through events/upcoming.html, the site-wide definition of "still ahead of us", so a release page never advertises a workshop that has already run; when the last one passes, the heading goes with it. Parameters: - anchor: Optional section ID for TOC link targets. - posts_title: Overline above the posts. Defaults to "More from the blog". - posts: Array of blog post paths (e.g. "/blog/some-post"). - events_title: Overline above the events.
