{{- /* On-demand events — the mirror of events/upcoming.html: everything that has already run and has a recording to watch. An event counts as on-demand once it is no longer upcoming (24 hours after its start time, matching upcoming.html) and it has a youtube_url, so the two helpers together partition the listed events exactly as the events list page does. Returns: a slice of dicts, newest-first (i.e. the most recent recording is index 0): date the event's sortable_date data the event page Global (depends only on site content), so callers should use partialCached with a constant key. */ -}} {{- $nowUnix := now.UnixMilli -}} {{- $onDemand := slice -}} {{- range where site.Pages "Type" "events" -}} {{- if and (eq .Params.unlisted false) .Params.youtube_url -}} {{- $endUnix := add (.Params.sortable_date | time.AsTime).UnixMilli (duration "hour" 24).Milliseconds -}} {{- if ge $nowUnix $endUnix -}} {{- $onDemand = $onDemand | append (dict "date" .Params.sortable_date "data" .) -}} {{- end -}} {{- end -}} {{- end -}} {{- return sort $onDemand "date" "desc" -}}
