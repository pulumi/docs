# Pulumi

> Infrastructure as code in real programming languages. Define, deploy, and manage cloud infrastructure on AWS, Azure, Google Cloud, Kubernetes, and hundreds of providers using TypeScript, JavaScript, Python, Go, .NET, Java, YAML, or HCL.

Pulumi is an open-source infrastructure as code platform that lets you use familiar programming languages and tools to build, deploy, and manage cloud infrastructure. Pulumi Cloud provides state management, secrets, deployments, governance, an internal developer platform, and infrastructure AI for teams. Pulumi works with the coding agent you already use (Claude Code, Codex, Cursor, and others), and Pulumi Neo is its purpose-built infrastructure agent.

## For agents

If you are an AI agent or programmatic consumer, start here. Each docs page linked below holds the full contract with copy-pasteable examples, and is also served as markdown.

- [Pulumi Cloud REST API via the CLI](https://www.pulumi.com/docs/iac/cli/api/): call any [Pulumi Cloud REST API](https://www.pulumi.com/docs/reference/cloud-rest-api/) endpoint with `pulumi api` (experimental), with a stable JSON error envelope and [exit codes](https://www.pulumi.com/docs/iac/cli/exit-codes/); `pulumi api list --output=json` returns the endpoint catalog
- [Pulumi Cloud OpenAPI spec](https://api.pulumi.com/api/openapi/pulumi-spec.json): the OpenAPI document `pulumi api` reads, for clients that call the REST API directly
- [Registry API for agents](https://www.pulumi.com/docs/reference/registry-api/): every published package, version by version (README, installation, nav, type docs, examples), with endpoints, parameters, and auth for private packages
- [Provider schemas](https://www.pulumi.com/docs/reference/registry-api/#provider-schemas): the full Pulumi schema for any provider, version-pinned through the Registry API or via `pulumi package get-schema <name>[@version]`
- [Markdown access](https://www.pulumi.com/docs/reference/registry-api/#markdown-access-to-docs-pages): every `/docs/` URL is served as markdown with `Accept: text/markdown` or a `.md` suffix (`/docs/iac/concepts/resources/` becomes `/docs/iac/concepts/resources.md`)
- [Docs index (JSON)](https://www.pulumi.com/docs/llm-sitemap.json): hierarchical sitemap of every page in the docs navigation, with titles and nesting; pageless headings are `"group": true` nodes with no `path`, off-site links carry `"external": true` and a `url`, and CLI command pages are listed at [/docs/iac/cli/commands/](https://www.pulumi.com/docs/iac/cli/commands/)
- [Context API](https://www.pulumi.com/docs/discovery-governance/concepts/context-api/): query one graph of IaC state, stack dependencies, and discovered cloud resources (public preview); fetch its schema with `pulumi api GetGraphQuerySchema`
- [CLI for agents](https://www.pulumi.com/docs/ai/concepts/cli-for-agents/): run any command with `npx pulumi`, with [one-shot resource operations](https://www.pulumi.com/docs/iac/cli/direct-resource-operations/) via `pulumi do` and an [ephemeral Pulumi Cloud account](https://www.pulumi.com/docs/administration/concepts/agent-accounts/) provisioned on first use
- [Coding agents](https://www.pulumi.com/docs/ai/coding-agents/): use Pulumi with the coding agent you already use (Claude Code, Codex, Cursor, and others)
- [Pulumi Agent Skills](https://www.pulumi.com/docs/ai/concepts/agent-skills/): proven Pulumi workflows for agents; install with `npx skills add pulumi/agent-skills/pulumi --skill '*'`
- [Agent Skills index](https://www.pulumi.com/.well-known/agent-skills/index.json): machine-readable list of the published Pulumi Agent Skills
- [Pulumi MCP server](https://www.pulumi.com/docs/ai/guides/set-up-mcp-server/): hosted MCP server exposing stacks, resource search, and the Registry as tools
- [MCP endpoint](https://mcp.ai.pulumi.com/mcp): the Streamable HTTP endpoint to add to an MCP client, e.g. `claude mcp add --transport http pulumi https://mcp.ai.pulumi.com/mcp`
- [MCP server card](https://www.pulumi.com/.well-known/mcp/server-card.json): machine-readable description of the Pulumi MCP server
- [API catalog](https://www.pulumi.com/.well-known/api-catalog): RFC 9727 linkset of Pulumi's public APIs
- [Hand off to Pulumi Neo](https://www.pulumi.com/docs/ai/coding-agents/handoff/): delegate an infrastructure task from a coding agent to Pulumi Neo
- [Support request API](https://www.pulumi.com/docs/support/support-request-api/): file a support ticket with one JSON POST to `https://www.pulumi.com/api/support`, no auth; never send a `leave_blank` key, it is a spam trap that silently discards the request

## Site overview

This llms.txt covers www.pulumi.com, which includes:

- [Product](https://www.pulumi.com/product/): Pulumi Cloud platform overview and capabilities
- [Get started](https://www.pulumi.com/up/): Guided first project for any cloud and language
- [Pricing](https://www.pulumi.com/pricing/): Pulumi Cloud editions and pricing ({{ delimit $editionNames ", " }})
- [Pulumi Registry](https://www.pulumi.com/registry/): Documentation for hundreds of cloud providers and components, available at `https://www.pulumi.com/registry/packages/<name>/`
- [Infrastructure AI](https://www.pulumi.com/docs/ai/): Write Pulumi code with [your coding agent](https://www.pulumi.com/docs/ai/coding-agents/), or investigate incidents and maintain infrastructure with [Pulumi Agents](https://www.pulumi.com/docs/ai/agents/), including the pre-built [Pulumi Neo](https://www.pulumi.com/docs/ai/concepts/neo/) and your own [custom agents](https://www.pulumi.com/docs/ai/agents/custom/)
- [Blog](https://www.pulumi.com/blog/): Product announcements, technical guides, and engineering posts
- [Releases](https://www.pulumi.com/releases/): Pulumi Cloud and CLI changelog, also available as [JSON](https://www.pulumi.com/releases/index.json) with edition availability per entry
- [Dev Center](https://www.pulumi.com/dev/): Tutorials, templates, community examples, and a glossary. Has an index of its own at [/dev/llms.txt](https://www.pulumi.com/dev/llms.txt), and every detail page has a markdown twin at its URL plus `.md`
- [Topics](https://www.pulumi.com/topics/): Explainer pages for cloud infrastructure concepts (e.g., infrastructure as code, Kubernetes, serverless). Has an index of its own at [/topics/llms.txt](https://www.pulumi.com/topics/llms.txt)
- [Customers](https://www.pulumi.com/customers/): Companies running their infrastructure on Pulumi, and the case studies behind them
- [Automation API](https://www.pulumi.com/automation/): Program-driven Pulumi for embedding infrastructure as code into applications and platforms
- [Whitepapers](https://www.pulumi.com/whitepapers/): Long-form educational and technical content
- [Community](https://www.pulumi.com/community/): Slack, Discord, GitHub, and other community resources
- [Security](https://www.pulumi.com/security/): Security posture, compliance, and trust information
- [Docs](https://www.pulumi.com/docs/): Technical documentation (detailed sections below)
