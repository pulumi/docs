{{/* stats — a row of big-number stat cards inside body copy. A thin wrapper, not a new component: it unmarshals its YAML body and hands the rows straight to layouts/partials/template-partials/template-counter-cards.html, which already renders exactly this. Reach for that partial directly from a template; this shortcode only exists so a markdown page can use it too. Params: align "left" or "center" (default, matching the partial) accent "violet" tints the numbers; omit for the default black anchor optional section id Body is YAML: a list of {number, label}. Usage: {{< stats align="left" accent="violet" >}} - number: "$700B" label: Hyperscaler capex in 2026, 75% of it AI-related {{< /stats >}} */}} {{- $cards := .Inner | transform.Unmarshal -}} {{- if not $cards -}} {{- errorf "stats: empty or unparseable YAML body (called from %s). Expected a list of {number, label}." $.Page.File.Filename -}} {{- end -}} {{- partial "template-partials/template-counter-cards.html" (dict "cards" $cards "align" ($.Get "align") "accent" ($.Get "accent") "anchor" ($.Get "anchor")) -}}
