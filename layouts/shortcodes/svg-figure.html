{{/* svg-figure — an inline SVG diagram with a numbered caption. Named `svg-figure`, not `figure`: Hugo ships a built-in `figure` shortcode that existing blog posts already use, and shadowing it would silently change them. The SVG is inlined rather than loaded through an because an -loaded SVG renders in an isolated document with no access to this page's @font-face rules. Figma pins every to an absolute x/y computed for the original font metrics, so a fallback face drifts every label out of its box. The diagram is never scaled below its native width — on a narrow viewport it scrolls sideways instead, the same affordance .table-wrapper gives a wide table. Above native width it grows to fill the column. Params: src path under assets/, e.g. "whitepapers/foo/fig-01.svg" (required) n figure number; rendered as the "Figure N." caption prefix alt text alternative for the diagram (required) Inner content is the caption body, rendered inline. Usage: {{< svg-figure src="whitepapers/foo/fig-01.svg" n="1" alt="…" >}} Caption text. {{< /svg-figure >}} */}} {{- $src := .Get "src" -}} {{- $n := .Get "n" -}} {{- $alt := .Get "alt" -}} {{- $svg := resources.Get $src -}} {{- if not $svg -}} {{- errorf "svg-figure: no asset at assets/%s (called from %s). Matching fingerprinted-img.html, a missing figure fails the build rather than rendering an empty box." $src $.Page.File.Filename -}} {{- end -}} {{- if not $alt -}} {{- errorf "svg-figure: src=%q needs an alt= describing the diagram (called from %s)." $src $.Page.File.Filename -}} {{- end -}} {{- /* Native width, so the scroll container knows how far it may shrink. Read the viewBox first (every Figma export declares one), falling back to the root element's own width attribute. Same findRE parse as layouts/partials/customer-logo.html. */ -}} {{- $nativeWidth := "" -}} {{- with findRE `viewBox=["'][^"']*["']` $svg.Content 1 -}} {{- $vb := substr (index . 0) 9 -1 -}} {{- $vbParts := split $vb " " -}} {{- if eq (len $vbParts) 4 -}} {{- $wCandidate := index $vbParts 2 -}} {{- if findRE `^[0-9.]+$` $wCandidate 1 -}} {{- $nativeWidth = $wCandidate -}} {{- end -}} {{- end -}} {{- end -}} {{- if not $nativeWidth -}} {{- with findRE `]*>` $svg.Content 1 -}} {{- with findRE `width="[0-9.]+"` (index . 0) 1 -}} {{- $nativeWidth = strings.TrimSuffix `"` (strings.TrimPrefix `width="` (index . 0)) -}} {{- end -}} {{- end -}} {{- end -}}
