{{/* Copy Prompt Shortcode Renders a prompt in full with a button that copies it, for pasting into a coding agent. The prompt is shown rather than truncated onto the button, so the reader can see what they're about to hand their agent. Usage: {{< copy-prompt track="docs-copy-onboarding-prompt" >}} Fetch https://www.pulumi.com/onboard.md and follow its instructions to get me started with Pulumi. {{< /copy-prompt >}} {{< copy-prompt label="Copy" track="docs-copy-migrate-prompt" >}}…{{< /copy-prompt >}} Parameters: - label (optional): button text (default: "Copy prompt") - track (optional): names the control in the analytics event copy-text.ts fires on a successful copy (default: "copy-prompt"). Set a specific one per placement so the events are distinguishable. The button is the generic [data-copy-text] control from theme/src/ts/copy-text.ts, registered globally in main.ts — no page-specific JS. Adapted from the "For agents" half of the /learn page in pulumi/docs#20698. */}} {{- $prompt := trim .Inner "\n " -}} {{- $label := .Get "label" | default "Copy prompt" -}} {{- $track := .Get "track" | default "copy-prompt" -}} {{- if not $prompt -}} {{- errorf "copy-prompt shortcode requires inner content (the prompt): %s" .Position -}} {{- end -}} {{- partial "copy-prompt.html" (dict "prompt" $prompt "label" $label "track" $track) -}}
