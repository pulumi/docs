{{/* Blog Body Card Shortcode Embeds an event or blog post card in the body of a post — the same tiles the events list and the blog homepage use, so an embedded event stays in sync with its event page for free (title, date chip, location, presenters, and the Register → Watch flip once a recording lands). Prefer this over hand-writing a `blog/cta-card` for an event: a CTA card has to restate the title, date, and blurb, and those copies go stale. Usage (one positional page path): {{< blog/card "/events/neo-in-a-docker-sandbox/" >}} {{< blog/card "/blog/pulumi-neo/" >}} The card is full width, never side by side: the text column is only so wide, and a full-width card reads as part of the post rather than as an ad unit. So one card per shortcode — several in a row is just several shortcodes. To label a card ("Americas", "EMEA"), write the label as ordinary markdown above it; the card is derived entirely from the target page and takes no copy of its own. Parameters (positional only): one absolute content path, resolving to a page under /events/ or /blog/.
