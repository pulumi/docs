[Start your first task](/docs/ai/get-started/neo/) to delegate work to Neo. To delegate and collaborate, [create an agent](/docs/ai/agents/configure/) and configure its system prompt and access.

To use a coding agent in your repository, start with [Pulumi skills](/docs/ai/concepts/agent-skills/). [Install the Pulumi CLI](/docs/ai/concepts/cli-for-agents/) if the agent needs to run previews or other commands. [Connect the MCP server](/docs/ai/guides/set-up-mcp-server/) if it needs to look up stacks, resources, or provider schemas.
