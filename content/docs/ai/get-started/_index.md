Assign infrastructure work to Pulumi Agents in Pulumi Cloud, or add Pulumi tools to the coding agent you already use.

<span id="use-pulumi-neo"></span>

## Use Pulumi Agents

[Start your first task with Neo](/docs/ai/get-started/neo/), the built-in agent in Pulumi Agents. You can try it without creating an agent or connecting a repository.

To delegate and collaborate, [create an agent](/docs/ai/agents/create-and-manage/) with saved instructions, tools, and permissions.

<span id="use-your-own-agent"></span>

## Use your coding agent

[Install Pulumi skills](/docs/ai/concepts/agent-skills/) in Claude Code, Codex, or another supported coding agent to give it instructions for writing Pulumi code and migrating infrastructure.

When the agent needs to run previews or other Pulumi commands, [set up the CLI](/docs/ai/concepts/cli-for-agents/). To let it look up stacks, resources, and provider schemas, [connect the Pulumi MCP server](/docs/ai/guides/set-up-mcp-server/).
