Pulumi works with the AI agent your team already uses, and with Pulumi Neo, Pulumi's own infrastructure agent. Many teams use both. Start with whichever path fits how you work.

## Use your own agent

Coding agents such as Claude Code, Codex, Cursor, and GitHub Copilot can write, preview, and deploy Pulumi programs directly.

1. Install [Pulumi Agent Skills](/docs/ai/concepts/agent-skills/) so your agent follows proven Pulumi workflows.
1. [Set up the Pulumi MCP server](/docs/ai/guides/set-up-mcp-server/) to give your agent access to your stacks, resources, and the Pulumi Registry.
1. Read how the [Pulumi CLI works for agents](/docs/ai/concepts/cli-for-agents/), including `npx pulumi`, `pulumi do`, and structured `--json` output.

## Use Pulumi Neo

Neo is Pulumi's infrastructure agent. It works with your organization's context, policy guardrails, and approvals, and it can run long or scheduled tasks on its own.

- [Get started with Pulumi Neo](/docs/ai/get-started/neo/): Enable Neo for your organization and run your first task.
