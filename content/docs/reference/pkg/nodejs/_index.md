* [**Pulumi SDK** (`@pulumi/pulumi`)](/docs/reference/pkg/nodejs/pulumi/pulumi/) — the core Pulumi SDK for Node.js.
* [**Pulumi Policy SDK** (`@pulumi/policy`)](/docs/reference/pkg/nodejs/pulumi/policy/) — for authoring policy packs for Pulumi Policies in TypeScript or JavaScript.
* [**Pulumi ESC SDK** (`@pulumi/esc-sdk`)](/docs/reference/pkg/nodejs/pulumi/esc-sdk/) — for programmatically interacting with Pulumi ESC (Environments, Secrets, and Configuration).

## Related guides and concepts

- [JavaScript and TypeScript language guide](/docs/iac/languages-sdks/javascript/): install, set up a project, and write your first program.
- [Inputs and outputs](/docs/iac/concepts/inputs-outputs/): how resource values flow through a program.
- [Resources](/docs/iac/concepts/resources/), [configuration](/docs/iac/concepts/config/), [secrets](/docs/iac/concepts/secrets/), and [stacks](/docs/iac/concepts/stacks/): the core programming model.
- [Automation API](/docs/iac/concepts/automation-api/): run Pulumi programmatically from your own code. The Node.js SDK documents it in the [automation module](/docs/reference/pkg/nodejs/pulumi/pulumi/modules/automation.html).
- [Pulumi Registry](/registry/): API documentation for cloud provider packages such as [AWS](/registry/packages/aws/api-docs/), [Azure Native](/registry/packages/azure-native/api-docs/), and [Kubernetes](/registry/packages/kubernetes/api-docs/).
