Self-hosted GitHub Enterprise operations may now be run as the individual user who triggered them, so pull requests, commits, and comments are attributed to that person and respect their permissions.

To learn more about this feature and how to configure it with your Pulumi organization, see [GitHub Enterprise Server support](/docs/integrations/version-control/github-app/#individual-user-authentication-for-github-enterprise-server) in the docs.
