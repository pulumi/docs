Self-hosted GitHub Enterprise operations now run as the individual user who triggered them, so pull requests, commits, and comments are attributed to that person and respect their permissions.

See the [GitHub app documentation](/docs/integrations/version-control/github-app/#individual-user-authentication-for-github-enterprise-server) for setup details.
