You can now create named [custom agents](/docs/ai/agents/custom/) in Pulumi Neo. Instead of one general-purpose assistant, you can define purpose-built agents — each with its own configuration and scope — and run them on the tasks they're suited for, from the Pulumi Cloud console or as part of an automation.

Give an agent a name, configure how it works, and it's ready to take on real infrastructure work on your behalf.

To learn more, see the [custom agents documentation](/docs/ai/agents/custom/).
