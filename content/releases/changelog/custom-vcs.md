Custom VCS integrations connect any Git or Mercurial version control system to Pulumi Cloud, including self-hosted and third-party servers. Store your credentials (SSH, basic auth, or a personal access token) in a Pulumi ESC environment, point the integration at your server, and pushes to your repository trigger Pulumi Deployments. Neo can clone and push to those repositories using the same credentials.

Read [the announcement](/blog/connect-any-git-server-to-pulumi-deployments-with-custom-vcs/) or set up your first integration with the [Custom VCS documentation](/docs/integrations/version-control/custom-vcs/).
