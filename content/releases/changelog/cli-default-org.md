---
title: Smarter default organization selection in the CLI
date: 2026-05-29
meta_desc: "Start a Pulumi Cloud trial and your trial org is now your default CLI org; you can also set a new org as your CLI default right from the console."
---

When you sign up for Pulumi Cloud and start a trial, your default CLI organization is now your trial org instead of your personal org. And when you create a new organization, the console asks whether to set it as your default CLI org, so the CLI lands in the right place from the start.
