This release contains critical fixes for destroyOnFinalize, making stack teardown and reconciliation more reliable.
It also contains quality-of-life feature additions such as better error condition messaging and allowing the flux source artifact size to be configurable.

For the full list of changes, see the [v2.8.0 release notes](https://github.com/pulumi/pulumi-kubernetes-operator/releases/tag/v2.8.0) on GitHub.
