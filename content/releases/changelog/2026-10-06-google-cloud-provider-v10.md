Version 10 of the [Pulumi Google Cloud provider](/registry/packages/gcp/) is now available. It brings the provider up to date with the latest upstream resources and APIs, along with the usual round of fixes and improvements.

Because this is a major version, some resources and properties have changed in breaking ways. To make the upgrade as painless as possible, we've published a migration guide — and an agent skill that can do much of the work for you.

To learn more, read the [announcement post](/blog/gcp-v10-release/).
